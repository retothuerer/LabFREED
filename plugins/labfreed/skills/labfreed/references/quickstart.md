# Quickstart: writing Python against `labfreed`

Every snippet below was executed end-to-end against the current package (requires
Python 3.14, per `pyproject.toml`); inline `#` comments show the actual values produced.
These examples build on each other -- imports and parsing aren't repeated for every
snippet. For the full, always-current version see the
"Usage Examples" section of https://github.com/retothuerer/LabFREED/blob/main/README.md
(auto-generated by executing `examples/examples.py`, so it never drifts from real
behavior).

## Parse and validate a PAC-ID

```python
from labfreed import PAC_ID, LabFREED_ValidationError

pac_str = 'HTTPS://PAC.METTORIUS.COM/-MD/bal500/@1234'
try:
    pac = PAC_ID.from_url(pac_str)
except LabFREED_ValidationError:
    pass  # from_url still returns a (marked-invalid) PAC_ID unless you ask it to raise

is_valid = pac.is_valid
print(f'PAC-ID is valid: {is_valid}')  # True -- lower-case chars are a RECOMMENDATION, not an ERROR

pac.print_validation_messages()  # pretty-prints every ERROR/RECOMMENDATION found, with the offending span highlighted
```

## PAC-CAT: read the identifier as categories

`PAC_ID.from_url()` automatically upgrades the result to a `PAC_CAT` when the identifier
is category-structured -- no separate parse step needed.

```python
from labfreed import PAC_CAT

pac_str = 'HTTPS://PAC.METTORIUS.COM/-DR/XQ908756/-MD/bal500/@1234'
pac = PAC_ID.from_url(pac_str)
if isinstance(pac, PAC_CAT):
    categories = pac.categories
    pac.print_categories()
```

## Extensions: read a display name and a T-REX payload off a PAC-ID

```python
pac_str = 'HTTPS://PAC.METTORIUS.COM/-MD/BAL500/1234*N$TEXT/WM633OV3E5DGJW2BEG0PDM1EA7*SUM$TREX/WEIGHT$GRM:67.89'
pac = PAC_ID.from_url(pac_str)

display_name = pac.get_extension('N')       # auto-converted to a DisplayNameExtension
print(display_name)                          # Text: My Balance ...

trexes = pac.get_extension_of_type('TREX')
trex = trexes[0].trex                        # could be multiple TREX extensions; there's one here
v = trex.get_segment('WEIGHT')
print(f'WEIGHT = {v.value}')                 # WEIGHT = 67.89
```

## Create a PAC-ID from scratch

```python
from labfreed import PAC_ID, IDSegment
from labfreed.well_known_keys.labfreed.well_known_keys import WellKnownKeys

pac = PAC_ID(issuer='METTORIUS.COM', identifier=[IDSegment(key=WellKnownKeys.SERIAL, value='1234')])
print(pac.to_url())  # HTTPS://PAC.METTORIUS.COM/21:1234
```

## Create a T-REX payload from a plain dict

`T_REX` is the pythonic facade layer -- build it from a dict, then call `.to_trex()` to
get the actual spec-conformant T-REX object.

```python
from datetime import datetime
from labfreed.trex.facade import T_REX, DataTable, Quantity

segments = {
    'STOP': datetime(2024, 5, 5, 13, 6),
    'TEMP': Quantity(value=10.15, unit='K'),
    'OK': False,
    'COMMENT': 'FOO',
}
mydata = T_REX(segments)

table = DataTable(col_names=['DURATION', 'DATE', 'OK', 'COMMENT'])
table.append([Quantity(value=1, unit='h'), datetime.now(), True, 'FOO'])
table.append([1.1, datetime.now(), True, 'BAR'])
mydata.update({'TABLE': table})

trex = mydata.to_trex()
trex.print_validation_messages()  # validation works the same way as for PAC_ID
```

## Attach a T-REX payload to a PAC-ID and serialize

```python
from labfreed.well_known_extensions import TREX_Extension

pac.extensions = [TREX_Extension(name='MYTREX', trex=trex)]
print(pac.to_url())  # HTTPS://PAC.METTORIUS.COM/21:1234*MYTREX$TREX/STOP$T.D:...+TEMP$KEL:10.15+...
```

## PAC-ID Resolver: resolve a PAC-ID to service links

See the terminology note in `concepts.md` -- `load_cit` still works (it's the CIT v1
loading path, now deprecated in favor of `ResolverConfig.from_yaml(...)`) but
`resolver_configs=` is the current parameter name either way.

```python
import os
import requests_cache
from labfreed import PAC_ID_Resolver, load_cit
from labfreed.pac_id_resolver.service_availability import check_service_group

cit = load_cit('path/to/cit_or_resolver_config.yaml')  # DeprecationWarning: use ResolverConfig.from_yaml(...)
cit.print_validation_messages()  # a config can be invalid too -- check before using it

pac_str = 'HTTPS://PAC.METTORIUS.COM/-MS/X3511/CAS:7732-18-5'
service_groups = PAC_ID_Resolver(resolver_configs=[cit]).resolve(pac_str, check_service_status=False)

cached_session = requests_cache.CachedSession(backend='memory', expire_after=60)
for sg in service_groups:
    check_service_group(sg, cached_session)  # needs network access to the resolver service(s)
    sg.print()
```

## PAC-ID Attributes: serve and query metadata for a PAC-ID

This is the core data model -- an in-memory data source, served in-process, no
Flask/network involved. For a real deployable server built on the same classes, see
`examples/pac_mettorius_com/README.md` in the repo.

```python
from labfreed.pac_attributes.facade.attributes import Attribute, Attributes, Resource
from labfreed.pac_attributes.facade.dict_data_source import Dict_DataSource
from labfreed.pac_attributes.well_known_attribute_keys import MetaAttributeKeys
from labfreed.pac_attributes.server.translation_data_sources import DictTranslationDataSource
from labfreed.pac_attributes.server.server import AttributeServerRequestHandler
from labfreed.pac_attributes.client.client import AttributeClient, local_attribute_request_callback_factory
from labfreed.utilities.translations import Terms, Term

pac_str = 'HTTPS://PAC.METTORIUS.COM/-MD/BAL500/000001'

# A data source could just as well read this from a database, an Excel sheet, or anywhere else.
# MetaAttributeKeys members are StrEnum -- usable directly wherever a str is expected, no .value needed.
data_source = Dict_DataSource(
    attribute_group_key=MetaAttributeKeys.GROUPKEY,
    data={
        pac_str: Attributes([
            Attribute(key=MetaAttributeKeys.DISPLAYNAME, value="My Balance"),
            Attribute(key=MetaAttributeKeys.IMAGE, value=Resource("https://picsum.photos/id/82/200")),
        ])
    }
)

# Attribute keys need a translation, so the server can label them for a UI
translations = DictTranslationDataSource(
    supported_languages={'en'},
    data=Terms(terms=[
        Term.create(MetaAttributeKeys.GROUPKEY, [('en', 'Meta Data')]),
        Term.create(MetaAttributeKeys.DISPLAYNAME, [('en', 'Display Name')]),
        Term.create(MetaAttributeKeys.IMAGE, [('en', 'Image')]),
    ])
)

# The request handler is the framework-agnostic core of an attribute server
handler = AttributeServerRequestHandler(data_sources=[data_source], translation_data_sources=[translations], default_language='en')

# Querying works the same whether the handler is embedded in a Flask app or called in-process, as here
client = AttributeClient(http_post_callback=local_attribute_request_callback_factory(handler))
attribute_groups = client.get_attributes(server_url='', subject_id=pac_str)
for group in attribute_groups:
    for attr in Attributes.from_payload_attributes(group.attributes):
        values = ', '.join(str(v) for v in attr.value_list)
        print(f'{attr.label}: {values}')
```
