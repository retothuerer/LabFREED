# Security Policy

## Supported Versions

This package is pre-1.0 and small (single maintainer, limited adoption). Only the
latest release on [PyPI](https://pypi.org/project/labfreed/) is supported — there is no
backport policy for older versions.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for a suspected security vulnerability.

Instead, either:

- Use GitHub's private reporting: [Security Advisories](https://github.com/retothuerer/LabFREED/security/advisories/new)
  for this repo, or
- Email the maintainer directly at `thuerer.r@buchi.com` with a description of the issue
  and, if possible, steps to reproduce it.

This is a small, mostly single-maintainer project without a formal SLA — expect an
acknowledgment within a few days, not a guaranteed response time. Once a fix is ready,
it will be released as a patch version and noted in `CHANGELOG.md`; credit is given in
the changelog/release notes unless you'd prefer to stay anonymous.
